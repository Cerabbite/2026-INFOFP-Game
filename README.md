# How to run the game?
Go into the astroids directory inside of you're terminal and type `cabal run`

# How to play the game?
You can control the player using WAD or the arrow keys. W or Up moves the player in the direction its pointing. A/D or Left/Right turn the player. Space is used for shooting. P is used to pause the game.
